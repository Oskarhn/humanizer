# Humanizer 1.1.1

Humanizer provides one shared prose-editing skill for Codex and Claude Code. It supports English, Bokmål, and Nynorsk, with selective references for genre, language, evidence, and provenance questions.

This maintenance version corrects two teaching examples, protects the strength of suggestions and approval claims, and makes the final check for invented causal or logical connections explicit. A new bilingual technical example keeps simulation results separate from physical verification.

The source repository includes English installation and usage documentation, retained evaluation records, standard-library helper scripts, reproducible release tooling, and CI configuration. It does not require a detector service or an API key for ordinary skill use.

The paired maintenance regression passed all five cases for both the old and new versions, with ties throughout. That shows no observed regression in this small run; it does not establish a quality improvement. The separate 98-output comparison used local 1.1.0, not this version. See [evaluation](../evaluation.md) for conditions and limits.

The archive keeps the full supporting directory structure. Follow [installation](../installation.md) and invoke `$humanizer` in Codex or `/humanizer` in Claude Code. Local skill installation does not upload the skill to a cloud account.
